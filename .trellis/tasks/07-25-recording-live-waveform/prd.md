# Recording live waveform meter

## Goal

录音开始后，根据实际收音电平动态显示波形，让用户在视觉上确认麦克风与系统声音均在被捕获。

## Requirements

- R1: 录音进行中展示实时波形（随电平变化）。
- R2: 电平来自真实捕获路径（麦 + 系统 loopback），而非前端另开一路假监听。
- R3: 视觉上可区分麦克风与系统声音活动（双轨或双色）。
- R4: 停止录音后波形停止并清理。
- R5: 尊重 `prefers-reduced-motion`（减弱装饰性动效，仍更新电平）。

## Acceptance Criteria

- [ ] AC1: 开始录音后出现波形区域。
- [ ] AC2: 对麦说话时麦克风轨明显抬升。
- [ ] AC3: 播放系统音频时系统轨明显抬升。
- [ ] AC4: 停止录音后波形消失。
- [ ] AC5: 波形风格与 Meetly 现有纸感 / 青绿 accent 一致，有设计感而非默认 equilizer 模板。

## Out of Scope

- 实时频谱分析、音量调节、回声消除。
- 将波形写入录音文件或回放可视化。
