# 侧边栏项目列表与转写总结迭代

## Goal

让用户能在桌面端浏览、切换、重命名与删除历史转写项目，按发言人阅读并修正转写，在生成摘要前选择语言，并一键复制摘要。

## Background

- 当前壳层为顶栏 + 主内容（`AppShell`），首页是单次导入转写流，无左侧项目列表。
- SQLite 已有 `meetings` / `transcripts` / `summaries` / `jobs`；IPC 无会议列表、无更新标题、无删除；`meetings.title` 可空（默认来自文件名 stem）。
- 外键为 `REFERENCES meetings(id)` **无** `ON DELETE CASCADE`，删除须在服务层按序清理关联行。
- `Transcript` 仅扁平 `text`（`raw_json` 未解析）。豆包 flash / async 均未开启发言人分离；豆包录音文件识别支持该能力。
- 摘要语言写死 `zh-CN`；摘要 UI 无复制；前序任务曾将多语言列为 out of scope，本迭代纳入有限三种语言。

## Decisions

| ID | Decision |
|----|----------|
| D1 | 中英文双语：每个条目内中英并列（`中文 / English`），仍为要点 / 待办 / 决策三块，不另起两套摘要。 |
| D2 | 发言人改名并应用更新转写后：删除该会议已有摘要，UI 提示需重新生成。 |
| D3 | 发言人识别：转写时启用豆包 ASR 原生分离；不另做 LLM 说话人识别。 |
| D4 | 侧边栏：整栏可收起/展开；列表项为可点击行；支持项目重命名（改 `title`）与删除。 |
| D5 | 摘要语言默认 `zh-CN`；可选 `en`、`zh-en`。 |
| D6 | 初始发言人显示名：`发言人1`、`发言人2`…；用户改名后写入映射并重渲染全文。 |
| D7 | 无发言人信息的历史转写：按纯文本展示，不显示改名面板。 |
| D8 | 删除为硬删除：确认后删除 meeting 及关联 `jobs` / `transcripts` / `summaries`；不删本地音频源文件。 |
| D9 | 重命名：更新 `meetings.title`；空标题不允许提交（trim 后非空）；侧边栏与主区 meta 同步显示新标题。 |

## Requirements

- R1: 左侧侧边栏列出历史转写项目（至少标题与时间）；整栏可隐藏/展开；点击项目加载该会议转写与已有摘要。
- R2: 新转写（flash 与 async）启用发言人分离；UI 展示分发言人内容；用户可编辑各发言人名并「应用」，更新整份转写文本并持久化（← D3, D6）。
- R3: 应用发言人改名后作废该会议摘要并提示重新生成（← D2）。
- R4: 生成摘要前可选 `zh-CN` | `en` | `zh-en`；`zh-en` 按 D1；语言传入 `summary_generate` 并写入 `Summary.language`（← D1, D5）。
- R5: 摘要区一键复制，剪贴板含三块结构化 Markdown（`##` 标题 + `-` 条目）。
- R6: 用户可重命名侧边栏项目标题（← D4, D9）。
- R7: 用户可删除侧边栏项目；删除前确认；硬删除会议及关联数据，不删除本地音频文件；若删的是当前打开项则回到空选态（← D4, D8）。
- R8: 侧边栏提供「新建项目」：清空当前选中，回到可导入音频的空工作区（不预创建空 meeting 行）。

## Out of Scope

- 实时转写/摘要；按发言人单独摘要；多模板。
- 三种以外的摘要语言；导出 PDF/Word。
- 云端同步；软删除/回收站；删除本地音频源文件。
- 为旧转写事后补跑发言人分离。

## Acceptance Criteria

- [ ] AC1: 侧边栏可见历史项目，可收起/展开；点击可切换会议并看到对应转写（及摘要若有）。← R1
- [ ] AC2: 新转写成功后可见发言人区分；改名并应用后全文标签更新，重启/重进仍保留。← R2
- [ ] AC3: 应用发言人改名后，已有摘要消失或不可用，并提示重新生成。← R3
- [ ] AC4: 生成前可选三种语言；`zh-en` 为逐条「中文 / English」；结果 `language` 与选择一致。← R4
- [ ] AC5: 一键复制后剪贴板含要点/待办/决策可读文本。← R5
- [ ] AC6: 可重命名项目，侧边栏与已打开会议的标题同步更新且持久。← R6
- [ ] AC7: 删除前有确认；确认后项目从列表消失且关联转写/摘要不可再加载；本地音频文件仍在；删除当前项后主区回到未选中态。← R7
- [ ] AC8: 侧边栏可点「新建项目」，主区回到未选中的导入态，可重新导入音频。← R8

## Technical Notes

- 新增 IPC：`meetings_list`、`meetings_rename`（或 `meetings_update`）、`meetings_delete`、发言人映射更新（并删摘要）、`summary_generate` 增加 `language`。
- `Transcript` 扩展 segments + speaker 显示名；`text` 仍为摘要输入用渲染全文。
- flash / async request 开启 `enable_speaker_info` + `show_utterances`（实现时按豆包文档核对配套参数）。
- 前端：`meeting-sidebar`（列表 / 收起 / 重命名 / 删除）；转写面板发言人编辑；摘要面板语言选择与复制。
