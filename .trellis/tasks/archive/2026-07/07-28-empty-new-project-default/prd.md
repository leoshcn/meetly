# 空态「新建项目」创建默认项目

## Goal

无项目时点击侧边栏「新建项目」应立即创建一个可见的默认项目，避免按钮无反馈造成困惑。

## Background

- 现状：`onNewProject` 仅清空选中并回到导入空态；当已是空态时点击无任何可见变化。
- 历史 R8（`07-25-sidebar-speaker-summary-iter`）曾明确「不预创建空 meeting 行」；本任务推翻该决策中的空态无反馈部分。
- Meeting 目前仅能经 `meetings_create_from_file` 创建，且 `source_path` 为必填；草稿需允许空 `source_path`，录音/导入后再挂载音频。

## Decisions

| ID | Decision |
|----|----------|
| D1 | 「新建项目」始终调用新建草稿 IPC，侧栏出现一行并选中；不再仅靠清空选中。 |
| D2 | 默认标题为「未命名项目」；`source_path` 为空字符串表示草稿。 |
| D3 | 选中草稿时主区仍显示录音/导入空态（与未选中时一致），不进入转写/摘要分栏。 |
| D4 | 在草稿上录音或导入时，把音频挂到该草稿（更新 `source_path` / 必要时标题），不另起一行。 |
| D5 | 若用户已重命名草稿，挂载音频时保留用户标题；仅在标题仍为默认「未命名项目」或空时改用文件名 stem。 |

## Requirements

- R1: 侧边栏「新建项目」（含收起态 +）创建默认标题「未命名项目」的草稿会议，出现在列表并被选中（← D1, D2）。
- R2: 无项目时空态点击「新建项目」有可见结果（列表出现新行）（← D1）。
- R3: 选中草稿时主区为录音/导入空态，可录音或导入（← D3）。
- R4: 草稿上完成录音/导入后，同一项目获得 `source_path` 并进入转写流程，不产生多余空项目（← D4, D5）。
- R5: 已有项目时点「新建项目」同样创建并选中新草稿（← D1）。

## Out of Scope

- 自动清理长期未使用的空草稿。
- 草稿数量上限或「新建」二次确认。
- 改变已有带音频项目的导入/重转录行为（非草稿路径保持 `create_from_file`）。

## Acceptance Criteria

- [x] AC1: 打开应用且无项目时，点「新建项目」后侧栏出现「未命名项目」并选中。← R1, R2
- [x] AC2: 选中该草稿时主区可录音或导入音频。← R3
- [x] AC3: 在该草稿上导入/录音并开始转写后，列表仍是同一行（标题可变为文件名），无残留空「未命名项目」。← R4
- [x] AC4: 已有其他项目时点「新建项目」会新增一行草稿并切过去。← R5
- [x] AC5: 用户先把草稿改名为自定义标题再导入，标题保持自定义名。← D5
